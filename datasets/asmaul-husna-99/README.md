# Asmaul Husna — 99 Names of Allah

Complete dataset of the 99 Names of Allah (al-Asma al-Husna) from the Quran and authentic hadith.

## Coverage

- 99 names, each with:
  - Arabic name (harakat/tashkil)
  - Latin transliteration
  - Indonesian translation
  - English translation
  - Quran reference(s)
  - Meaning/explanation in Indonesian

## Source

Classical public domain Islamic knowledge. The 99 Names are derived from the Quran and the hadith of Prophet Muhammad SAW (HR. Bukhari & Muslim).
