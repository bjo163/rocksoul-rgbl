# Bhagavad Gita — Complete 700 Verses

The Bhagavad Gita (Song of the Blessed One), classical 700-verse Sanskrit scripture that is part of the Hindu epic Mahabharata (Bhishma Parva, chapters 23–40).

## Coverage
- Complete 700 verses across all 18 chapters:
  1. Arjuna Viṣhād Yoga (47 verses)
  2. Sānkhya Yoga (72 verses)
  3. Karma Yoga (43 verses)
  4. Jñāna Karma Sanyās Yoga (42 verses)
  5. Karma Sanyās Yoga (29 verses)
  6. Dhyāna Yoga (47 verses)
  7. Jñāna Vijñāna Yoga (30 verses)
  8. Akṣhara Brahma Yoga (28 verses)
  9. Rāja Vidyā Yoga (34 verses)
  10. Vibhūti Yoga (42 verses)
  11. Viśhwarūpa Darśhana Yoga (55 verses)
  12. Bhakti Yoga (20 verses)
  13. Kṣhetra Kṣhetrajña Vibhāga Yoga (35 verses)
  14. Guṇa Traya Vibhāga Yoga (27 verses)
  15. Puruṣhottama Yoga (20 verses)
  16. Daivāsura Sampad Vibhāga Yoga (24 verses)
  17. Śhraddhā Traya Vibhāga Yoga (28 verses)
  18. Mokṣha Sanyās Yoga (78 verses)

- Each verse includes:
  - Original Sanskrit text in Devanagari script (`text`)
  - Standard International Alphabet of Sanskrit Transliteration (IAST Latin script)
  - Sanskrit word-by-word gloss (`word_meanings`)
  - Complete English translation (Swami Sivananda / Swami Adidevananda)
  - Canonical chapter and verse citation path (`[chapter, verse]`)
