# Sahih al-Bukhari (Core Foundation Baseline)

Foundational canonical hadith collection from Sahih al-Bukhari (Al-Jami' al-Sahih al-Musnad) by Imam Muhammad ibn Isma'il al-Bukhari (194–256 AH / 810–870 CE).

## Coverage
- 100 foundational hadiths covering:
  - Book of Revelation (Bad' al-Wahy)
  - Book of Faith (Kitab al-Iman)
  - Book of Knowledge (Kitab al-'Ilm)
- Each report includes:
  - Complete Arabic text (isnad and matn) with full vocalization (harakat)
  - English translation
  - Hadith numbering aligned with canonical standard numbering
  - Scholarly grade (Sahih)

## Rights & Provenance
- Source: Classical public domain hadith corpus.
- Ingestion endpoint: UmmahAPI Hadith Service.
- Rights: CC0-1.0 Public Domain.
