# Sahih al-Bukhari — Complete Collection

Complete canonical hadith collection from Sahih al-Bukhari (Al-Jami' al-Sahih al-Musnad) by Imam Muhammad ibn Isma'il al-Bukhari (194–256 AH / 810–870 CE).

## Coverage
- Complete 7,580 hadiths across all 97 books (Wahy, Iman, Ilm, Salah, Zakah, Sawm, Hajj, Nikah, Buyu', Jihad, Tafsir, Adab, Da'awat, Tawhid, etc.)
- Each report includes:
  - Complete Arabic text (isnad and matn) with full vocalization (harakat)
  - English translation
  - Standard canonical hadith numbering
  - Scholarly grade (Sahih)
