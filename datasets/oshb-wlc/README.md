# OSHB/WLC

This dataset bundles the Westminster Leningrad Codex source text and OSHB morphology evidence from `openscriptures/morphhb` commit `3d15126fb1ef74867fc1434be1942e837932691f`. The source manifest records per-file checksums and the upstream archive checksum.

The WLC text is public domain according to the upstream OSHB metadata. Lemma and morphology annotations are attributed to Open Scriptures under CC BY 4.0. Do not remove that attribution when redistributing this dataset.
