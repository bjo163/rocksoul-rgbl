# Wikidata P13 discovery snapshot

The `.rq` files document the bounded discovery baseline. `entities/*.json` are immutable downloaded entity snapshots containing exact `lastrevid`, multilingual labels/aliases, statements, and references as returned by Wikidata on 2026-08-27. Wikidata QIDs remain external identifiers and are not MoonWitness canonical identity.

The baseline is intentionally non-exhaustive. It proves the reproducible snapshot and reconciliation lane; later revisions expand coverage through reviewed snapshots rather than live unpinned queries.
