# World English Bible Classic 2020

This is the full ecumenical book set from eBible.org's verse-per-line World English Bible Classic export. It includes 38,058 reference slots across 79 source book codes; 29 source slots are intentionally empty and remain explicit in the dataset.

The text is public domain. “World English Bible” remains an eBible.org trademark; do not use that edition name for modified text.
