# Yoga Sutras of Patanjali (Pātañjalayogasūtra / पातञ्जलयोगसूत्र)

Foundational classical Sanskrit text of the Yoga school of Hindu philosophy, attributed to sage Patañjali.

## Coverage
- 195 foundational sutras across all 4 Pādas (Chapters):
  1. Samādhi Pāda (51 sutras — On Meditative Absorption)
  2. Sādhana Pāda (55 sutras — On the Practice and Eight Limbs / Ashtanga)
  3. Vibhūti Pāda (55 sutras — On Spiritual Attainments and Subtle Powers)
  4. Kaivalya Pāda (34 sutras — On Absolute Liberation and Isolation of Consciousness)
- Each sutra includes:
  - Original Sanskrit text in Devanagari script (`sa`)
  - Standard IAST Latin transliteration (`transliteration`)
  - Clear English translation (`en`)
  - Canonical citation path (`[pada, sutra]`)
