# P13 World Religions & Persons Registry v0.1

Status: bounded, reproducible baseline plus seven exact textual-evidence links. The registry contains 148 baseline records and the evidence layer contains 9 metadata records. Wikidata QIDs, revision metadata, and SHA-256s are retained in the pinned snapshot manifest.

The exit gates pass for scoped roles, bounded/non-final taxonomy, and identity records carrying external IDs. Automatic duplicate merges are disabled. Coverage is intentionally non-exhaustive: indigenous and modern movement discovery, richer aliases/native names, sourced cross-tradition equivalence, and historicity assessments remain explicit gaps in `datasets/p13-coverage.json`.

Exact evidence currently links Quran 2:87 and 33:40, WLC Exodus 3:1 and Genesis 12:1, and SBLGNT 1 Corinthians 1:1. Source text is not duplicated by the P13 layer; dependency manifests govern its rights.
