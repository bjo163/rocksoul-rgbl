# P14 dataset diversity coverage report

The current corpus has six bundled diversity lanes spanning Quran, Hebrew Bible, Greek New Testament, Buddhist scripture, and Indonesian Bible material. It also records metadata-only discovery lanes for hadith, commentary, Jewish legal/commentarial texts, non-Abrahamic primary texts, and living traditions.

The matrix is intentionally not an exhaustiveness claim. Rights, source-language boundaries, translation status, text scale, and unresolved gaps are recorded independently. Restricted or consent-dependent material is not bundled.
